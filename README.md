# AI Interview Preparation Bot

This project is a simple AI-based student career guide using Python and streamlit.

## Features
- takes marks as input from students
- calculates and shows them graphically for better understanding using matplotlib.py
- evaluates best career choice
- Provides score and feedback

## Technologies Used
- Python
- streamlit
- json
- matplotlib

## Future Improvements
- Voice-based question answering
- fully automated AI based  chatbot
